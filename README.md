# pull-request-test

This repository is for testing pull requests and GitHub workflows.

## Purpose

- Try out opening, reviewing, and merging pull requests
- Test branch protection, CI checks, and review settings
- Experiment safely without affecting real projects

## Usage

1. Create a branch: `git checkout -b my-test-branch`
2. Make a change and commit it
3. Push the branch and open a pull request

> Note: Content in this repository is for testing only.
